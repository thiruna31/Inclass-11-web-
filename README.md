## Project Overview

This project demonstrates JavaScript objects, DOM manipulation, event handling, timers, and interactive web application development through three activities:

1. **Tic-Tac-Toe:** An interactive game with player turns, win detection, game reset, and a computer opponent.
2. **Heartbeat Tracker:** An animated heartbeat application using JavaScript timers and interactive controls.
3. **DOM Events Study Page:** An interactive page for reviewing JavaScript DOM events and recording checklist completion.
